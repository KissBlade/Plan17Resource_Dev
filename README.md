本项目是一个基于 [Nebula on the Ship](https://github.com/Dolly1016/Nebula) 编写的插件。\
加入了一些**职业与功能**，整体采用 C# 语言编写。

## 贡献指南

### 在开始前
为 Plan17 Add-On 贡献代码前，你需要具备如下条件：
- 了解如何使用 Git 命令行工具与如何创建 [Pull Request](https://docs.github.com/zh/pull-requests/how-tos/create-pull-requests/creating-a-pull-request)。
- 熟悉 C# 开发，了解 [Nebula on the Ship](https://github.com/Dolly1016/Nebula) 的插件开发流程。
- 能够在 Pull Request 中清晰、条理地描述你作出的修改。

### 让我们开始吧！

- 你需要使用 `git clone` 从 Github 上克隆本仓库。
- 在每次开发前，你需要使用 `git checkout -b xxx/xxxxxx` 创建一个新的分支，分支名**最好**与你本次变更的**代码内容**相关。
- 完成开发后，你需要创建一个 Pull Request，你的提交信息格式最好使用 [Conventional Commits](https://www.conventionalcommits.org)。
- 在确保**代码已测试通过、已同步主分支最新代码、至少一名审查者的批准**后，你可以将当次 Pull Request 合并到主分支。
